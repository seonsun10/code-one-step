# 제품 규칙

## 제품 목표

프로그래밍 언어와 프레임워크를 배우는 사람이 설명을 읽고, 다양한 방식으로 연습하고, 기록을 보존해 다음 학습을 이어갈 수 있는 웹사이트를 만든다.

## 사용자 경험 원칙

- 방문자는 계정을 만들거나 결제하지 않고도 핵심 학습 콘텐츠를 이용할 수 있어야 한다.
- 학습자는 주제나 언어를 선택해 학습 경로를 시작하고, 현재 진도와 다음 할 일을 쉽게 찾을 수 있어야 한다.
- 오답은 실패 표시만 남기지 않고 정답 근거와 다시 시도할 수 있는 경로를 제공한다.
- 문제마다 학습 목표, 난이도, 예상 시간, 정답 또는 평가 기준을 표시한다.
- 넓은 주제 목록보다 정확하고 설명이 충실한 시작 콘텐츠를 우선한다.

## 초기 범위 제안

- UI 언어: 한국어 우선.
- 학습 트랙 예시: JavaScript, Python, Java 기초와 Spring Boot 및 React 입문.
- 문제 유형: 객관식, 짧은 주관식, 코드에서 오류 위치 찾기, 잘못된 코드 고르기, 코드 수정·리팩터링, 브라우저에서 실행하는 JavaScript 코딩 문제.
- 튜토리얼·개념 카드·힌트·풀이·복습 표시를 공통 학습 단위로 제공한다.
- 다른 언어와 프레임워크는 설명 및 문제 콘텐츠부터 늘린다. 브라우저 안에서 안전하게 실행할 수 없는 언어의 자동 실행 채점은 서버 실행 설계가 승인될 때까지 제공하지 않는다.

## 무료 제공과 수익화

- 초기 공개 버전은 로그인과 결제 없이 전 사용자에게 동일한 핵심 학습 경험을 제공한다.
- 초기 버전에 유료 잠금, 구독 유도 배너, 결제 UI, 결제 SDK를 만들지 않는다.
- 향후 멤버십은 콘텐츠 확장 수요와 유지 비용이 확인된 뒤 별도 단계로 검토한다. 무료 핵심 경로를 해치지 않으며, 유료 기능의 범위와 가격을 사용자에게 명확히 표시한다.
- 유료 기능의 실제 구현 전에는 결제·세금·환불·계정·데이터 보관 요구사항을 새 결정으로 기록한다.

## 범위 판단

새 기능은 학습 효과, 진도 지속성, 무료 운영 가능성 중 적어도 하나를 명확히 개선해야 한다. 광고, 소셜 피드, 순위표, 복잡한 프로필, 대규모 저작 도구는 핵심 학습 흐름이 검증되기 전까지 미룬다.
