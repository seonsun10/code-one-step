# 개인정보 및 보안 규칙

## 데이터 최소화

- 초기 버전은 계정, 이메일, 실명, 비밀번호, 서버 분석 이벤트를 요구하지 않는다.
- 사용자 진도와 답안은 기본적으로 사용자 브라우저에만 저장한다.
- 내보내기 파일에 개인 식별 정보나 불필요한 브라우저 데이터가 들어가지 않도록 한다. 가져오기 전에 데이터 크기와 구조를 검증하고 미리보기 또는 명확한 확인 상태를 제공한다.
- 브라우저 데이터가 삭제되거나 기기를 바꾸면 자동 동기화되지 않는다. 안내와 백업/복구 기능으로 기대치를 분명히 한다.

## 임의 코드 및 콘텐츠 입력

- 사용자가 입력한 코드와 가져온 콘텐츠를 신뢰하지 않는다.
- 임의 코드는 메인 UI 스레드에서 실행하지 않는다. 별도 Worker에서 실행하되, 이를 완전한 보안 경계라고 설명하지 않는다.
- 코드 실행에 인증 정보, 비공개 정답 데이터 외의 서버 데이터, 로컬 파일 접근, 부모 창의 참조를 넘기지 않는다.
- Worker 종료, 시간 제한, 출력 제한, 오류 처리와 메모리 증가 대응을 검증한다.
- HTML 삽입이나 위험한 문자열 실행으로 가져온 Markdown·텍스트를 렌더하지 않는다. 필요하면 안전한 렌더링 정책을 적용한다.
- 강한 격리 실행이 필요한 언어와 채점은 서버 실행 환경의 격리 방식, 악용 방지, 비용, 로그·보관 정책을 승인받기 전까지 제공하지 않는다.

## 서비스 도입 전 필수 기록

외부 데이터 전송 또는 비용이 발생할 수 있는 서비스를 추가하기 전 다음을 기록한다: 목적, 전송 데이터, 보관 위치/기간, 계정 및 삭제 방식, 무료 한도와 초과 비용, 보안 책임, 대체 방법, 승인된 구현 범위.
