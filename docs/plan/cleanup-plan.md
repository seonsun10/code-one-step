# 품질 정리 계획

날짜: 2026-10-09
상태: 완료

## 범위와 기준선

- 대상: `src/styles.css`, `src/main.js`
- 유지할 동작: 현재 라우트와 학습 흐름, 모바일 고정 탐색, 문제 입력·피드백, 코드 복사 기능
- 기준선 검사: `npm test` 9/9 통과, `npm run build` 성공
- 화면 기준선: 데스크톱 1280px과 모바일 390×844에서 홈 콘텐츠와 반응형 내비게이션을 확인했다.

## 정리 순서

1. 한국어 본문·문항·조작 글씨 중 14px 미만인 핵심 텍스트를 가독성 있는 크기로 올린다. 장식용 eyebrow와 코드 글꼴은 별도로 둔다.
2. 클립보드 API가 없는 환경에서도 복사 버튼이 오류를 던지지 않게 명시적인 지원 여부를 처리한다.
3. 화면 규칙 회귀 검사와 기존 테스트·빌드를 실행하고 390px, 1280px 화면을 다시 확인한다.

## 임시 우회 분류

- 코드 복사 핸들러의 선택적 체이닝은 클립보드 API가 없는 경우 `undefined.then`을 호출할 수 있다. 오류를 숨기는 우회가 아니라 불완전한 기능 검출이므로 명시적인 API 검사와 안내 문구로 고친다.
- CSS에는 정리 범위에서 우회 분기가 발견되지 않았다.

## 디자인 검토

- 확인된 문제: 홈 모바일 캡처에서 설명, 카드 본문, 버튼 보조 문구가 7–12px로 렌더링되어 초보 학습 콘텐츠를 읽기 어렵다.
- 조치: 핵심 텍스트의 최소 크기를 올리고 기존 공간 구조를 유지한다. 코드·장식용 표식은 이번 범위에서 유지한다.

## 완료 증거

- 본문, 문항 설명과 조작 요소는 `--reading-min: 14px`를 적용했고 모바일 하단 탐색도 14px로 키웠다.
- 코드 복사 API 미지원 및 거부 상태에 오류 안내를 표시한다.
- `npm test` 11/11 통과, `npm run build` 성공, 390×844와 1280px 화면에서 문서 가로 넘침 없음.
