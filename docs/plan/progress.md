## 상태 규칙

- 단계 상태는 `대기`, `진행`, `차단`, `완료` 중 하나로 쓴다.
- 단계는 완료 조건을 모두 확인한 다음에만 `완료`로 바꾼다.
- 차단 사유와 필요한 결정은 `docs/plan/decisions-and-help.md`에 기록하고 여기에는 해당 ID를 연결한다.
- 완료율은 체감치가 아니라 체크 항목과 근거로 산정한다.
- 화면 너비 1280px 및 390×844 브라우저 렌더링을 확인했고 두 화면 모두 문서 가로 넘침이 없었다. 모바일 내비게이션 전환과 핵심 글자 크기도 확인했다.
- OMX Ultragoal 추적은 `session.json`/`OMX_SESSION_ID` 권한 연결 오류로 차단되어 있다(E-02). 현재 Codex 목표도 `blocked`로 확인됐다. 숨겨진 런타임 상태는 임의로 고치지 않고 실제 제품 근거는 이 문서에 기록한다.
- 공개 학습 사이트는 [code-one-step.pages.dev](https://code-one-step.pages.dev/)에 배포됐다. GitHub Issues는 제보 경로로 연결되어 있으며 제보 시 GitHub 로그인이 필요하다고 화면에 표시한다. OMX Ultragoal 추적은 별도 세션 권한 문제로 차단되어 있다(E-02); 제품 단계 완료 증거는 이 문서와 저장소 Git 기록에서 관리한다.
