# 학습 콘텐츠 현황과 다음 단계 후보

최종 갱신: 2026-10-10 (Asia/Seoul)

## 현재 카탈로그 기준

현재 카탈로그에는 JavaScript 5개, Python 5개, Java 5개, Spring Boot 4개, React 4개로 총 23개 단원이 있다. 각 트랙은 3단계로 나뉘고 모든 단원에 번호, 앞 단원 선수 관계, 연습 문제, 힌트, 해설이 연결된다. 시작 단원은 트랙의 단계 개요부터 열리며, 이후에는 이어서 풀 단원으로 이동할 수 있다.

문항은 객관식·짧은 주관식·오류 줄 찾기·코드 수정·JavaScript 실행 문제를 포함한다. 코드 수정 문항은 서버에서 실행하지 않고 명시한 코드 조건을 검사한다. JavaScript 코딩 문제만 기존 브라우저 Worker 실행기를 사용한다.

| 트랙 | 검토 기준 | 단계 구성 | 단원 수 | 검토 일자 |
|---|---|---|---:|---|
| JavaScript | ECMAScript 2026 / ECMA-262 17판 (최종, 2026년 6월) | 값과 변수 → 조건과 반복 → 함수와 배열 | 5 | 2026-10-10 |
| Python | Python 3.15.0 안정판 (2026-10-09 공개) | 값과 변수 → 조건과 반복 → 함수와 리스트 | 5 | 2026-10-10 |
| Java | Java SE 25 LTS | 타입과 변수 → 조건과 반복 → 메서드와 객체 | 5 | 2026-10-10 |
| Spring Boot | Spring Boot 4.1.1 / Framework 7.0.9 이상 | 의존성 주입 → 웹 요청 → 서비스와 입력 검증 | 4 | 2026-10-10 |
| React | React 19.3 | 컴포넌트와 props → 이벤트와 상태 → 상태 객체 업데이트 | 4 | 2026-10-10 |

최신 버전 표기는 2026-10-10에 공식 출처를 다시 확인한 기준이다. Python 3.15.0은 2026-10-09 공개된 안정판이며, 새 버전 전용 기능은 공통 기초와 분리한다. ECMAScript 2026은 ECMA-262 17판 최종 명세, Java SE 25는 LTS 기준이며 Java SE 27 비-LTS 및 미리보기 기능을 일반 기초 문법과 혼합하지 않는다. Spring의 Java 호환 범위와 각 프레임워크의 범위는 [단계별 공식 출처](../../src/curriculum-additions.js)에 기록한다. 버전이 바뀌면 출처와 검토 날짜를 다시 확인한다.

이 문서는 콘텐츠 후보이지 공개 일정이나 최종 사용자 우선순위 결정이 아니다. 첫 공개 후 실제 피드백을 반영해 순서를 바꾼다(H-02).

## 범위와 순서 규칙

- 먼저 23개 기존 단원의 답과 사용자 피드백을 검토한다. 다음에 JavaScript와 Python 자료 구조/예외처럼 기본 단계 뒤에 필요한 내용을 보강한다.
- Java 자료 구조와 객체지향 내용을 확인한 다음 Spring Boot와 React의 데이터/요청 흐름을 확장한다.
- 버전별 심화 단원에는 지원 종료, preview, 호환성에 관한 날짜가 바뀔 수 있는 설명을 최신 공식 출처로 재검증한다.
- Spring Boot 콘텐츠는 정적 코드 설명·선택·오류 찾기·수정 문제로 구성한다. 서버 실행, 데이터베이스, 사용자 계정이나 외부 API를 추가하지 않는다.
- 자동 코드 실행은 기존처럼 JavaScript 브라우저 샌드박스에만 둔다. 다른 언어는 이론·코드 읽기 문제로 학습한다.
- C 묶음은 실제 학습자가 막히는 선수 개념과 접근성 피드백을 확인한 뒤 제작한다.

## 단원 공개 기준

각 단원은 `docs/rules/content.md`와 `docs/rules/design.md`를 따라 다음을 채운 뒤 공개한다.

1. 학습 목표, 난이도, 예상 시간, 선수 지식과 적용 언어/프레임워크 맥락
2. 짧은 개념 설명과 실행 결과를 확인할 수 있는 코드 예제
3. 적어도 하나의 연습 문제, 힌트, 오답 또는 실수에 대한 설명, 정답 풀이
4. 객관식의 모든 보기에 개별 설명 또는 코드 문제의 예상 변경·결과
5. 해당 문법/기능을 확인할 공식 문서 출처와 검토 날짜·버전
6. 고유 ID, 트랙 연결, 채점 규칙, 빌드와 자동 카탈로그 검증

로그인·분석 추적 없이 공개 Issues 피드백과 명시적으로 제공된 브라우저 오류 제보만 콘텐츠 우선순위 조정에 사용한다.
