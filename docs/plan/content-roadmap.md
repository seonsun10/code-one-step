## 전체 단계 교육과정 고도화 (2026-10-11)

## 범위와 순서 규칙

- 기존 공개 문항을 유지하고 확장 단원은 선수 개념에서 시작해 고급·실전으로 이어지게 한다.
- 버전별 심화 단원에는 지원 종료, preview, 호환성에 관한 날짜가 바뀔 수 있는 설명을 공식 출처로 재검증한다.
- Spring Boot와 React는 실행 프로젝트가 아닌 명시된 버전의 개념 코드 문제로 구성한다. 서버, 데이터베이스, 계정, 동기화나 외부 API를 추가하지 않는다.
- 자동 코드 실행은 현재 JavaScript 브라우저 실행기에서 시작한다. 다른 언어 런타임은 무료·정적·보안·라이선스 기준을 통과한 경우에만 별도 계획으로 추가하며, 그전에는 이론·코드 읽기·수정 문제로 학습한다.
- 예비 콘텐츠 묶음은 실제 학습자가 막히는 선수 개념과 접근성 피드백을 확인한 뒤 후보로 추가한다. G10에서 정한 다섯 트랙의 60단원·180문항과 혼동하지 않도록 공개 후보와 현재 카탈로그를 구분한다.

## 단원 공개 기준

각 단원은 `docs/rules/content.md`와 `docs/rules/design.md`를 따라 다음을 채운 뒤 공개한다.

1. 학습 목표, 난이도, 예상 시간, 선수 지식과 적용 언어/프레임워크 맥락
2. 짧은 개념 설명과 실행 결과를 확인할 수 있는 코드 예제
3. 서로 다른 목표를 다루는 연습 문제 세 개와 각각의 힌트·오답 설명·정답 풀이
4. 객관식의 모든 보기에 개별 설명 또는 코드 문제의 예상 변경·결과
5. 해당 문법/기능을 확인할 공식 문서 출처와 검토 날짜·버전
6. 고유 ID, 트랙 연결, 채점 규칙, 빌드와 자동 카탈로그 검증
