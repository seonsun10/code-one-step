# 26주 학습 경로 확장

## 왜 다시 늘리는가

현재 각 트랙은 12단원·36문항이고, 화면의 예상 시간을 모두 더해도 트랙별 약 2시간뿐이다. 다섯 단계는 숙련도 표시에 가깝고 6개월 자기주도 과정을 설명하지 못한다. 사용자의 지적을 반영해 다섯 단계를 최종 과정처럼 제시하는 방식을 끝낸다.

## 목표 기준

각 언어/프레임워크를 따로 선택해 **26주 동안 주 5일 공부하는 과정**으로 설계한다. 하루에는 하나의 개념/코드 목표, 예제, 세 문제, 연습 활동을 둔다. 하루 60–90분을 기준으로 하면 선택한 트랙을 약 6개월 동안 체계적으로 이어갈 수 있다.

| 항목 | 트랙 하나 | 다섯 트랙 전체 |
|---|---:|---:|
| 학습 주차 | 26주 | 130주차 묶음 |
| 학습일/세션 | 130일 | 650일 세션 |
| 문제 | 390문제 | 1,950문제 |
| 학습 구간 | 6개 구간 | 트랙마다 6개 |

학습 시간은 목표치이며 숙달을 보장하지 않는다. 이 경로는 4년제 컴퓨터공학과의 알고리즘·수학·컴퓨터구조·운영체제·네트워크·팀 프로젝트 전체를 대체하지 않는다. 더 넓은 컴퓨터과학 기초 과정은 별도 확장 후보로 둔다.

## 여섯 학습 구간

1. 1–4주: 도구, 값, 문법, 실행 흐름
2. 5–8주: 함수, 자료 구조, 기본 문제 해결
3. 9–12주: 모듈, 오류, 테스트, 자료 처리
4. 13–16주: 프로그램 구조와 프레임워크 핵심 흐름
5. 17–21주: 고급 기능, 성능, 보안, 접근성, 운영 경계
6. 22–26주: 누적 복습, 설계 과제, 프로젝트와 설명/검토

트랙마다 주제 배치는 기술 특성에 맞춰 다르게 한다. Spring Boot는 Java 객체지향·HTTP 기초를, React는 JavaScript 함수·객체·비동기 기초를 먼저 다룬다. 다른 언어의 코드를 서버에서 실행하는 기능은 추가하지 않는다.

## 콘텐츠와 UI 규칙

- 26주를 하나의 긴 목록으로 늘어놓지 않고 여섯 구간 아래 묶는다.
- 주차 안에서 월~금 학습 목표와 그날의 세 문제를 확인할 수 있어야 한다.
- 홈과 문제 화면은 예: `7주차 · 수요일 · 2/3문제`로 현재 위치를 알려준다.
- 15개 주간 문제를 모두 맞히면 그 주를 완료한다. 틀린 문제는 다시 풀 수 있다.
- 기존 문제와 답안 ID를 보존하고, 예전 완료 기록은 보존 표시와 새 주차 완료를 구분한다.
- 정확성/해설/버전 출처가 검수되지 않은 문제는 완료 수량에 넣지 않는다.
- Spring/React 예제는 실행 검증이 없으면 개념 코드라고 표시한다.

## 현재 상태 및 완료 기준

다섯 트랙의 편집 검수는 **100%**다: JavaScript 26/26주, Python 26/26주, Java 26/26주, Spring 26/26주, React 26/26주로 총 **130/130 트랙-주차·1,950/1,950문항**을 승인했다. 다섯 트랙의 26주·주 5일·주 15문항 구조, 주차/일차 탐색과 기존 진도 호환이 구현됐다. 모든 주차에서 다섯 날짜의 목표·예시·문항 중복, 공개 정답 키와 채점, 오류 위치·설명, 수정 시작 코드, 코드 추적 출력 결과를 자동 회귀 검사한다. Python 과정 문서는 Python 3.15 계열 기준으로 대조했다. Python 3.15.1은 2026-10-21 공개된 최신 안정판이다. 예제는 로컬 Python 3.12.10에서 실행했으며 Python 3.15.1에서 실행한 것은 아니므로, 3.15.1 런타임 호환성을 검증했다고 볼 수 없다. Java 25 LTS/JDK 27 비-LTS, Spring Boot 4.1.1/Framework 7.0.9, React 19.3, ECMAScript 2026을 공식 자료로 반영했다. 최종 전체 검증 수치와 브라우저 진도/백업 복원 상태는 [진척 기록](progress.md)을 따른다. Spring 예시는 실제 프로젝트에서 컴파일하지 않은 개념 스니펫이다. G11 로컬 변경은 아직 공개하지 않았으며 G10 공개 카탈로그 60단원·180문항과 구분한다.
