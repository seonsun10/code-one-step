# 결정 사항, 오류 및 도움 요청

최종 갱신: 2026-10-10 (Asia/Seoul)

## 승인된 기본 결정

| ID | 결정 | 이유/영향 | 재검토 조건 |
|---|---|---|---|
| D-01 | 초기 버전은 로그인·서버·DB 없이 만든다. | 초기 비용과 운영 부담을 없애고 공개 접근을 단순하게 유지한다. | 여러 기기 동기화 또는 계정별 데이터가 꼭 필요해질 때 |
| D-02 | 진도와 풀이 기록은 브라우저에 저장하고 JSON 백업/복원을 제공한다. | 서버 비용 없이 같은 브라우저에서 이어서 학습할 수 있다. | 사용자가 계정 기반 동기화를 요구할 때 |
| D-03 | UI는 한국어 우선이며 초보자도 시작할 수 있게 한다. | 현재 요구에 맞춘 시작 기준이다. | 사용자 피드백에서 언어/숙련도 변경이 필요할 때 |
| D-04 | 브라우저 코드 자동 채점은 JavaScript로 시작한다. | 서버 실행 비용 없이 제공 가능한 첫 실행 범위다. | 다른 언어 실행 수요와 안전한 실행 환경이 검증될 때 |
| D-05 | 전체 핵심 학습은 무료로 공개하고 멤버십·결제는 뒤로 미룬다. | 먼저 사용자와 학습 수요를 모은다. | 지속 비용과 유료 콘텐츠 수요를 확인한 뒤 |
| D-06 | 학습 트랙 시작 예시는 JavaScript, Python, Java, Spring Boot, React다. | 언어와 프레임워크 학습 요구를 초기 카탈로그에 반영한다. | 첫 콘텐츠 제작 전 사용자가 우선순위를 변경할 때 |
| D-07 | 초기 앱은 브라우저 기본 HTML/CSS/ES 모듈만으로 만들고 패키지 의존성을 두지 않는다. | npm 레지스트리 응답이 없어 설치를 취소했다. 소스 그대로 정적 제공이 가능하고 운영 비용·외부 의존성이 없다. | 유지보수성이 저하되거나 구체적인 기능 요구가 생길 때 |
| D-08 | 각 학습 트랙에 검수 상태, 검토 날짜, 적용 버전 맥락, 공식 문서 출처를 기록하고 화면에서 연결한다. | Framework 문서가 바뀌어도 어떤 맥락을 확인했는지 사용자가 추적할 수 있다. | 공식 출처가 이동하거나 학습 내용이 수정될 때 출처·검토 날짜 갱신 |
| D-09 | 초기 로컬 기록 규격은 IndexedDB DB/store v1과 JSON 진행 파일 v1로 고정한다. 변경 시 명시적 변환 없이는 알 수 없는 형식의 가져오기를 거부한다. | 첫 버전은 과거 기록 마이그레이션이 필요 없고, 잘못된 파일 때문에 현재 기록을 덮어쓰지 않게 한다. | v2 스키마가 필요해져 변환 및 회귀 검사를 추가할 때 |
| D-10 | 무료 공개 호스팅 후보는 Cloudflare Pages 정적 사이트다. 초기 배포는 Git 연동, `npm run build`, `dist/` 출력이며 Pages Functions·DB·Worker API·유료 기능은 사용하지 않는다. | 현재 공식 무료 한도는 월 500회 빌드, 사이트당 20,000개 파일, 파일당 25 MiB이며 정적 요청은 무료·무제한으로 문서화돼 있다. 미래 구독/상업 기능은 별도 약관 및 비용 검토 전까지 추가하지 않는다. | 저장소 연결/공개 전, 무료 한도 변경 시, 또는 구독·상업 기능 도입 전 |
| D-11 | 다섯 초기 트랙은 3개의 번호 단계와 선형 선수 단원 순서를 제공하며, 첫 진입은 트랙의 단계 개요에서 시작한다. | 문제를 차근차근 풀되 점수로 다음 단원을 잠그지 않는다. 객관식·주관식·오류 찾기·코드 수정·JavaScript 실행 문제를 함께 제공한다. | 학습자 피드백에서 단계 구성이나 진입 흐름을 바꿀 근거가 나올 때 |
| D-12 | 화면 테마 기본값은 기기 설정이고, 밝게/어둡게 선택은 브라우저에 저장한다. | 사용자가 고른 테마는 시스템 색상 변경에 덮이지 않아야 하며 설정은 로컬에만 남는다. | 브라우저 테마 동작이 바뀌거나 접근성 피드백이 들어올 때 |
| D-13 | 사이트 이름은 `코드한걸음 (Code One Step)`으로 정하고 공개 GitHub 저장소와 이름을 맞춘다. | 사용자가 만든 `seonsun10/code-one-step` 저장소 이름이 앞서 제안한 브랜드와 일치한다. 기존 코드 기호를 워드마크와 함께 사용하고 별도 로고 자산은 추가하지 않는다. | 사용자 피드백에서 브랜드 변경을 요청할 때 |

## 기록 규칙

- 재현 가능한 구현 오류는 증상, 재현 절차, 기대 동작, 실제 동작, 관련 단계, 다음 조치를 기록한다.
- 사용자의 도움이 필수인 결정만 `차단`으로 표시한다. 지금 합의된 기본안으로 안전하게 계속할 수 있는 결정은 차단하지 않는다.
- 해결하면 해결 날짜·결정·영향받는 계획 항목을 추가하고 상태를 갱신한다.
- G8 공개는 Cloudflare Pages 배포 성공과 라이브 URL의 주요 경로·제보 링크 확인 후 완료 처리한다. 현재 배포 근거와 주소는 `docs/plan/progress.md` 및 이 항목에 기록했다.
- 현재 최종 버전 표는 2026-10-10 재확인값이며, 버전 변경 시 공식 출처와 호환 범위를 재검증한다. 다섯 트랙 확장 후의 다음 콘텐츠는 [콘텐츠 로드맵](content-roadmap.md)에 정리했다.
